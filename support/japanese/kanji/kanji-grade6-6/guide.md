# 小学6年 地域沿恩人灰内閣株干巻看護簡単

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 域 | いき |  | ある範囲・区域のこと |
| 沿 | そ | えん | 川や道のそばに続いて行くこと |
| 恩 | おん |  | お世話になった気持ち・恩義 |
| 灰 | はい | かい | 物が燃えたあとに残る粉 |
| 閣 | かく |  | 内閣・閣議など、国の大臣が集まる組織を指す |
| 株 | かぶ | しゅ | 切り株・株式など |
| 干 | ほ | かん | 水分をとばして乾かすこと |
| 巻 | ま | かん | くるくると丸めること |
| 看 | かん |  | よく見て世話をすること |
| 簡 | かん |  | 単純でわかりやすいこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
