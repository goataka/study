# 小学5年 独立燃破備豊暮領土余夢務

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 独立 | どくりつ |  | 他に頼らず自分でやっていくこと |
| 燃 | も | ねん | 火がついて焼けること |
| 破 | やぶ | は | 壊すこと・やぶくこと |
| 備 | そな | び | 必要なものを用意しておくこと |
| 豊 | ゆた | ほう | 十分にあって満ちていること |
| 暮 | く | ぼ | 生活すること |
| 領土 | りょうど |  | 国が支配する土地 |
| 余 | あま | よ | 余分に残ること |
| 夢 | ゆめ | む | 眠っているときに見るもの・将来の目標 |
| 務 | つと | む | 仕事を担当すること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
