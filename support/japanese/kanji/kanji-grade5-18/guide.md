# 小学5年 規律留勢支織資源限

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 律 | りつ |  | 守るべききまり・リズムのこと |
| 留 | とど | る | 動かずにいること・そこに残ること |
| 勢 | いきお | せい | 力強い様子・勢力のこと |
| 支 | ささ | し | 下から支えること |
| 織 | お | しょく | 糸を組み合わせて布を作ること |
| 資 | し |  | 元手・資源のこと |
| 限 | かぎ | げん | 範囲を決めること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
