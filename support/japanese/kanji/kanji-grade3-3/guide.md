# 小学3年 駅横開寒漢字岸起客急球

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 駅 | えき |  | 電車が止まる場所 |
| 横 | よこ | おう | 左右の方向のこと |
| 開 | あ | かい | とじていたものをひらくこと |
| 寒 | さむ | かん | 気温が低くてひんやりすること |
| 漢字 | かんじ |  | 中国から伝わった文字 |
| 岸 | きし | がん | 海や川のはしっこの土地 |
| 起 | お | き | ねむりから目がさめること |
| 客 | きゃく |  | 訪ねてくる人・お店に来る人 |
| 急 | いそ | きゅう | はやく動くこと |
| 球 | たま | きゅう | まるい形のもの |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
