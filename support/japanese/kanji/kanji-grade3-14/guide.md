# 小学3年 今度投大豆お湯登等動童話農業波

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 度 | ど |  | 回数・程度のこと |
| 投 | な |  | ものを飛ばすこと |
| 豆 | まめ |  | 植物の種実 |
| 湯 | ゆ | とう | 熱いお湯のこと |
| 登 | のぼ | とう | 高い所へ行くこと |
| 等 | ひと | とう | 同じであること |
| 動 | うご | どう | 位置が変わること |
| 童 | わらべ | どう | 子どものこと |
| 農 | のう |  | 作物を育てる仕事 |
| 波 | なみ | は | 海や水面のうねり |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
