# 小学6年 宇宙憲法批判探求異革命展望縮小複雑純粋

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 宇宙 | うちゅう |  | 地球の外にある広大な空間 |
| 憲法 | けんぽう |  | 国の基本的なきまりを定めたもの |
| 批判 | ひはん |  | 物事のよしあしを判断すること |
| 探求 | たんきゅう |  | 深く追い求めること |
| 異 | こと | い | 違うこと |
| 革命 | かくめい |  | 社会や制度を根本から変えること |
| 展望 | てんぼう |  | 遠くを見渡すこと・将来の見通し |
| 縮小 | しゅくしょう |  | 小さくすること |
| 複雑 | ふくざつ |  | 入り組んでいて難しいこと |
| 純粋 | じゅんすい |  | 混じりけがないこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
