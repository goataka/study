# 小学6年 一枚幕秘密同盟模型訳欲翌日乱一覧

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 枚 | まい |  | 薄いものを数える単位 |
| 幕 | まく |  | 舞台などに張る布・区切り |
| 密 | みつ |  | 隠していること・細かくびっしりしていること |
| 盟 | めい |  | 誓い合って結ぶ約束・団体 |
| 模 | も |  | 形を写したもの・手本のこと |
| 訳 | わけ | やく | 理由・意味のこと |
| 欲 | ほ | よく | 手に入れたいと思うこと |
| 翌 | よく |  | 次の・その次のこと |
| 乱 | みだ | らん | 整っていたものが崩れること |
| 覧 | らん |  | 見ること・見渡すこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
