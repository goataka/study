# 小学5年 格差額発刊幹慣眼寄久旧友居

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 格 | かく |  | 等級・地位のこと |
| 額 | ひたい | がく | 顔の上部のこと |
| 刊 | かん |  | 本や新聞などを出版すること |
| 幹 | みき | かん | 木の太い中心部分 |
| 慣 | な | かん | 何度もやって馴染むこと |
| 眼 | め | がん | 目のこと・見る力のこと |
| 寄 | よ | き | 近くに行くこと・立ち寄ること |
| 久 | ひさ | きゅう | 長い時間が経っていること |
| 旧 | きゅう |  | 古い・以前のこと |
| 居 | い | きょ | その場所にいること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
