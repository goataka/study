# 小学3年 消商売勝植申真っ赤進全部相手送

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 消 | き | しょう | なくなること |
| 商売 | しょうばい |  | 物を売り買いして利益を得ること |
| 勝 | か | しょう | 試合や争いでよい結果になること |
| 植 | う | しょく | 種や苗を土に入れること |
| 申 | もう | しん | 「言う」の丁寧な言い方 |
| 真 | ま | しん | 完全に赤いこと |
| 進 | すす | しん | 前に動いていくこと |
| 全部 | ぜんぶ |  | 残らずすべてのこと |
| 相手 | あいて |  | いっしょに行動する人・向こう側の人 |
| 送 | おく | そう | ものや人をある場所に届けること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
