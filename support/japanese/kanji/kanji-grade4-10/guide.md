# 小学4年 菜材料昨日散残氏名歴史司会辞書借

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 菜 | な | さい | 食べられる植物の葉や茎 |
| 材料 | ざいりょう |  | 物を作るための原料・もとになるもの |
| 昨日 | きのう |  | 今日の前の日 |
| 散 | ち | さん | ばらばらになること |
| 残 | のこ | ざん | 余ること・後に残ること |
| 氏名 | しめい |  | 名字と名前のこと |
| 歴史 | れきし |  | 昔から今までの出来事の記録 |
| 司会 | しかい |  | 会の進行を取り仕切ること |
| 辞書 | じしょ |  | 言葉の意味や読み方を調べる本 |
| 借 | か | しゃく | 一時的に使わせてもらうこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
