# 小学3年 委員会会員病院中央屋根化荷物一階図書館期間

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 委 | い |  | 仕事をまかせること |
| 員 | いん |  | 仲間の一人 |
| 院 | いん |  | 建物や施設を表す |
| 央 | おう |  | まんなかのこと |
| 屋 | や |  | 建物のてっぺんの部分 |
| 化 | ば |  | 姿が変わること |
| 荷 | に |  | 運ぶ物 |
| 階 | かい |  | 建物の層 |
| 館 | かん |  | 大きな建物 |
| 期 | き |  | ある時の間 |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
