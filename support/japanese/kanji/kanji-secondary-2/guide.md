# 中学生 繁栄哲学本質価値観象徴喜怒悩企業現象

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 繁栄 | はんえい |  | 豊かに栄えること |
| 哲学 | てつがく |  | 物事の根本的な意味を考える学問 |
| 本質 | ほんしつ |  | 物事の根本・真の姿 |
| 価値観 | かちかん |  | 何に価値があるかについての考え方 |
| 象徴 | しょうちょう |  | 何かを表すものやしるし |
| 喜 | よろこ |  | うれしく思うこと・楽しく感じること |
| 怒 | おこ |  | 腹を立てること・激しく感情をあらわにすること |
| 悩 | なや |  | どうしたらよいか迷い苦しむこと |
| 企業 | きぎょう |  | 利益を目的として事業を行う組織 |
| 現象 | げんしょう |  | 目に見える形で現れた出来事や状態 |

## 💡 学習のコツ

- 単語の **文脈** の中で意味を理解して覚える
- **例文** を作って実際に使ってみよう
- 同義語・反意語も合わせて確認すると理解が深まる
