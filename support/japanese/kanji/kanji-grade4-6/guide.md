# 小学4年 印衣類景色各自管理軍隊訓練積説明倉庫

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 印 | しるし | いん | 目印となるマーク |
| 衣類 | いるい |  | 服のこと |
| 景色 | けしき |  | 自然の眺めのこと |
| 各自 | かくじ |  | それぞれの人 |
| 管理 | かんり |  | 物事をしっかり扱うこと |
| 軍隊 | ぐんたい |  | 国を守るための兵士の集まり |
| 訓練 | くんれん |  | くり返し練習して上達すること |
| 積 | つ | せき | 重ねて高くすること |
| 説明 | せつめい |  | 物事をわかりやすく伝えること |
| 倉庫 | そうこ |  | 物をしまっておく建物 |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
