# 小学4年 郡型芸術欠固功績好天候告差

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 郡 | ぐん |  | 市や町をまとめた地域の行政区分 |
| 型 | かた | けい | 決まった形・パターン |
| 芸術 | げいじゅつ |  | 絵・音楽・彫刻などの美しい表現 |
| 欠 | か | けつ | 一部が足りなくなること |
| 固 | かた | こ | やわらかくなくしっかりしていること |
| 功績 | こうせき |  | 努力してあげた優れた成果・手柄 |
| 好 | す | こう | 気に入っていること |
| 天候 | てんこう |  | 数日間の天気の状態 |
| 告 | つ | こく | 知らせること・伝えること |
| 差 | さ |  | 二つの違い・数の引き算の答え |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
