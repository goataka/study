# 小学4年 命令冷例連老苦労不思議付兵士別

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 命令 | めいれい |  | 上の人が下の人に言いつけること |
| 冷 | つめ | れい | 温度が低いこと |
| 例 | たと | れい | 説明のために示すこと |
| 連 | つ | れん | 一緒に連れていくこと |
| 老 | お | ろう | 年をとること |
| 苦労 | くろう |  | 苦しみながら努力すること |
| 不 | ふ |  | 否定を表す接頭語 |
| 付 | つ | ふ | くっつけること |
| 兵 | へい |  | 軍人・戦士のこと |
| 別 | わか | べつ | 離れること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
