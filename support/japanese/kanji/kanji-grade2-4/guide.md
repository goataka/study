# 小学2年 形光考国今心声星晴雪

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 形 | かたち | けい | 物の外見のこと |
| 光 | ひかり | こう | 明るく照らすもの |
| 考 | かんが | こう | 頭で思うこと |
| 国 | くに | こく | 国家のこと |
| 今 | いま | こん | 現在のこと |
| 心 | こころ | しん | 気持ちや感情のこと |
| 声 | こえ | せい | 口から出る音のこと |
| 星 | ほし | せい | 夜空に光る天体のこと |
| 晴 | は | せい | 空が晴れること |
| 雪 | ゆき | せつ | 空から降る白い結晶のこと |

## 💡 学習のコツ

- 訓読みは **日本語のことば** としてイメージして覚える
- 読み方だけでなく **書き方** も合わせて練習しよう
- クイズで繰り返し練習するとおぼえやすい
