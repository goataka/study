# 小学1年 車十出女人正夕千早村

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 車 | くるま | しゃ | 乗り物のこと |
| 十 | とお | じゅう | 数の10のこと |
| 出 | で | しゅつ | 中から外へ行くこと |
| 女 | おんな | にょ | 女性のこと |
| 人 | ひと | にん | 人間のこと |
| 正 | ただ | しょう | 間違いがないこと |
| 夕 | ゆう |  | 日が沈む頃の時間のこと |
| 千 | せん |  | 数の1000のこと |
| 早 | はや | そう | 時間がかからないこと、時刻が前であること |
| 村 | むら | そん | 小さな集落のこと |

## 💡 学習のコツ

- 訓読みは **日本語のことば** としてイメージして覚える
- 読み方だけでなく **書き方** も合わせて練習しよう
- クイズで繰り返し練習するとおぼえやすい
