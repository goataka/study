# 中学生 結論仮定比例変量依頼縁怠惜描揺

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 結論 | けつろん |  | 考えや議論の最終的なまとめ・判断 |
| 仮定 | かてい |  | 仮にそうだと想定して考えること |
| 比例 | ひれい |  | 一方が増えると他方も同じ割合で増える関係 |
| 変量 | へんりょう |  | データの中で変化する数値・統計で扱う量 |
| 依頼 | いらい |  | 相手にお願いして頼むこと |
| 縁 | えん |  | 人と人をつなぐ関係・つながり・きっかけ |
| 怠 | おこた |  | すべきことをせず、なまけること |
| 惜 | お |  | 残念に思うこと・大切にして手放したくないと思うこと |
| 描 | えが |  | 絵をかくこと・心の中で思い浮かべること |
| 揺 | ゆ |  | 左右・上下に動くこと・心が不安定になること |

## 💡 学習のコツ

- 単語の **文脈** の中で意味を理解して覚える
- **例文** を作って実際に使ってみよう
- 同義語・反意語も合わせて確認すると理解が深まる
