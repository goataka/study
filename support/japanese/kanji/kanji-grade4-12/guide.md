# 小学4年 浅戦自然巣束側卒業孫帯単語

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 浅 | あさ | せん | 深くないこと |
| 戦 | たたか | せん | 争うこと・力で勝ち負けを決めること |
| 自然 | しぜん |  | 山・川・空など人が作っていないもの |
| 巣 | す | そう | 鳥や虫が住む場所 |
| 束 | たば | そく | まとめてくくったもの |
| 側 | がわ | そく | ある方向の面・横の部分 |
| 卒業 | そつぎょう |  | 学校の課程を終えること |
| 孫 | まご | そん | 子どもの子ども |
| 帯 | おび | たい | 着物を締める布 |
| 単語 | たんご |  | 一つひとつの言葉のまとまり |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
