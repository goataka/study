# 小学5年 順序招承知証拠常情条件職業制度政治

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 序 | じょ |  | 順番・始まりのこと |
| 招 | まね | しょう | 呼び寄せること・招待すること |
| 承 | しょう |  | 受け入れること・分かること |
| 証 | しょう |  | 確かめるもの・証明するもの |
| 常 | つね | じょう | いつものこと・普通の状態 |
| 情 | なさ | じょう | 思いやりの気持ちのこと |
| 条 | じょう |  | 項目・決まりのこと |
| 職 | しょく |  | 仕事・役目のこと |
| 制 | せい |  | 定めること・仕組みのこと |
| 政 | せい |  | 国を治めること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
