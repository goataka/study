# 小学2年 歩会切算図明汽少数台

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 歩 | ある | ぶ | 足で移動すること |
| 会 | あ | え | 人と顔を合わせること |
| 切 | き | さい | 刃物などでものを切ること |
| 算 | さん |  | 計算すること |
| 図 | はか | と | 計画する・図面のこと |
| 明 | あか | みょう | 光があって明るいこと |
| 汽 | き |  | 水蒸気のこと |
| 少 | すく | しょう | 数量が少ないこと |
| 数 | かず | す | 数えた結果のこと |
| 台 | だい |  | 台・乗り物などを数える助数詞 |

## 💡 学習のコツ

- 訓読みは **日本語のことば** としてイメージして覚える
- 読み方だけでなく **書き方** も合わせて練習しよう
- クイズで繰り返し練習するとおぼえやすい
