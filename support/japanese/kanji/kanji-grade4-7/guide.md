# 小学4年 案内以上囲栄一億貨物課題芽改機械

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 案内 | あんない |  | 道や場所を教えること |
| 以上 | いじょう |  | それより多いか同じであること |
| 囲 | かこ | い | まわりを取り囲むこと |
| 栄 | さか | えい | 勢いよく育つこと |
| 一億 | いちおく |  | 一万の一万倍の数 |
| 貨物 | かもつ |  | 船や電車で運ぶ荷物・品物 |
| 課題 | かだい |  | 取り組むべき問題・しなければならないこと |
| 芽 | め | が | 植物が芽吹くときの小さな部分 |
| 改 | あらた | かい | 悪いところを直してよくすること |
| 機械 | きかい |  | 動力で動く装置・道具 |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
