# 小学1年 男竹中虫町天田二入八

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 男 | おとこ | なん | 男性のこと |
| 竹 | たけ | ちく | まっすぐ伸びる植物のこと |
| 中 | なか | ちゅう | 内側・まんなかのこと |
| 虫 | むし | ちゅう | 小さな生き物のこと |
| 町 | まち | ちょう | 人が集まって住んでいる場所のこと |
| 天 | てん |  | 空・天上のこと |
| 田 | た | でん | 稲を育てる水を張った土地のこと |
| 二 | ふた | に | 数の2のこと |
| 入 | はい | にゅう | 外から中へ行くこと |
| 八 | やっ | はち | 数の8のこと |

## 💡 学習のコツ

- 訓読みは **日本語のことば** としてイメージして覚える
- 読み方だけでなく **書き方** も合わせて練習しよう
- クイズで繰り返し練習するとおぼえやすい
