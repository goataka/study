# 中学生 影響根拠批評観点立場対話協力秩序自由平等

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 影響 | えいきょう |  | あるものが別のものに変化をもたらすこと |
| 根拠 | こんきょ |  | 判断や主張の基となる理由や証拠 |
| 批評 | ひひょう |  | 物事のよしあしを判断して意見を述べること |
| 観点 | かんてん |  | 物事を見る立場・視点 |
| 立場 | たちば |  | その人が置かれている状況や役割・地位 |
| 対話 | たいわ |  | 向かい合って話し合うこと・ダイアログ |
| 協力 | きょうりょく |  | 力を合わせて物事に取り組むこと |
| 秩序 | ちつじょ |  | 社会や物事が正しく整っている状態・決まりある順序 |
| 自由 | じゆう |  | 他から束縛されず自分の意思で行動できること |
| 平等 | びょうどう |  | すべての人が同じ扱いを受けること |

## 💡 学習のコツ

- 単語の **文脈** の中で意味を理解して覚える
- **例文** を作って実際に使ってみよう
- 同義語・反意語も合わせて確認すると理解が深まる
