# 小学6年 刻穀物骨砂済対策冊子蚕至私

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 刻 | きざ | こく | 細かく切ること・時を刻むこと |
| 穀 | こく |  | 米・麦などの食用植物の種 |
| 骨 | ほね | こつ | 体の骨格・苦労すること |
| 砂 | すな | しゃ | 細かい石の粒・砂浜 |
| 済 | す | さい | 終わること・解決すること |
| 策 | さく |  | 計画・方法のこと |
| 冊 | さつ |  | 本を数える単位・小さい本 |
| 蚕 | かいこ | さん | 絹の糸を作る虫 |
| 至 | いた | し | ある場所や状態に達すること |
| 私 | わたし | し | 自分のこと・個人のこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
