# 小学4年 選争続望満足養録音辺法律未来

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 選 | えら | せん | いくつかの中から決めること |
| 争 | あらそ | そう | 互いに張り合うこと |
| 続 | つづ | ぞく | やめずに同じことをすること |
| 望 | のぞ | ぼう | こうなってほしいと思うこと |
| 満足 | まんぞく |  | 不満がなく十分なこと |
| 養 | やしな | よう | 育てること |
| 録音 | ろくおん |  | 音を記録すること |
| 辺 | あた | へん | まわりのこと |
| 法律 | ほうりつ |  | 国が定めたきまり |
| 未来 | みらい |  | これから先のこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
