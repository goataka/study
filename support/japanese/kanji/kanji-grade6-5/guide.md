# 小学6年 脳批評閉補訪忘優論文朗読幼

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 脳 | のう |  | 頭の中にある体の司令塔 |
| 批評 | ひひょう |  | 物事のよしあしを判断して述べること |
| 閉 | と | へい | 開いているものをふさぐこと |
| 補 | おぎな | ほ | 足りない部分を足すこと |
| 訪 | たず | ほう | 人を会いに行くこと |
| 忘 | わす | ぼう | 覚えていたことを思い出せなくなること |
| 優 | やさ | ゆう | 思いやりがあること |
| 論文 | ろんぶん |  | 研究した結果をまとめた文章 |
| 朗読 | ろうどく |  | 声に出して読むこと |
| 幼 | おさな | よう | 年齢が小さいこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
