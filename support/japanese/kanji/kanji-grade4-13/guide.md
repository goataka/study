# 小学4年 博物館ご飯費用投票夫府副会長粉便利包

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 博物館 | はくぶつかん |  | 歴史や自然の物を展示する施設 |
| ご飯 | ごはん |  | 炊いた米・食事のこと |
| 費用 | ひよう |  | 何かをするためにかかるお金 |
| 投票 | とうひょう |  | 選挙などで選ぶために紙に書いて出すこと |
| 夫 | おっと | ふ | 結婚した相手の男性 |
| 府 | ふ |  | 都道府県の一つ |
| 副会長 | ふくかいちょう |  | 会長を補佐する役職 |
| 粉 | こな | ふん | 細かくくだいたもの |
| 便利 | べんり |  | 使いやすくて役に立つこと |
| 包 | つつ | ほう | 物をおおうこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
