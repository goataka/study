# 小学6年 机指揮貴疑吸胸故郷筋系統警察

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 机 | つくえ | き | 本や物を置いて使う台 |
| 揮 | き |  | 指揮・発揮など、力をふるうこと |
| 貴 | とうと | き | 価値が高く大切なこと |
| 疑 | うたが | ぎ | 本当かどうか確かでないと思うこと |
| 吸 | す | きゅう | 息や液体を体の中に取り込むこと |
| 胸 | むね | きょう | 体の前の部分・心のこと |
| 郷 | きょう |  | 生まれ育った土地・ふるさと |
| 筋 | すじ | きん | 体の筋肉・話の流れ |
| 系 | けい |  | つながり・系列のこと |
| 警 | けい |  | 危険を知らせること・取り締まること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
