# 小学5年 肥非常俵貧婦人富弁護士保墓報告

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 肥 | こ | ひ | 太ること・土地が豊かになること |
| 非 | ひ |  | 否定を表す言葉 |
| 俵 | たわら | ひょう | 米などを入れる袋 |
| 貧 | まず | びん | お金がなく生活が苦しいこと |
| 婦 | ふ |  | 女性・奥さんのこと |
| 富 | と | ふ | 豊かであること・たくさん持っていること |
| 弁 | べん |  | 話すこと・弁護すること |
| 保 | たも | ほ | 持続させること・守ること |
| 墓 | はか | ぼ | 死者を葬ったところ・お墓 |
| 報 | ほう |  | 知らせること・返すこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
