# 中学生 漸次顕著曖昧斟酌忸怩懊悩憔悴蹉跌矜持僭越

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 漸次 | ぜんじ |  | しだいに・少しずつ |
| 顕著 | けんちょ |  | はっきりと目立つこと |
| 曖昧 | あいまい |  | はっきりしないこと・はっきり判断できないこと |
| 斟酌 | しんしゃく |  | 相手の事情をくみ取って配慮すること |
| 忸怩 | じくじ |  | 恥ずかしくて心苦しいこと（忸怩たる思い） |
| 懊悩 | おうのう |  | 思い悩んで苦しむこと・深く煩悶すること |
| 憔悴 | しょうすい |  | 心身ともに疲れ果て、やつれること |
| 蹉跌 | さてつ |  | 物事が失敗・挫折すること |
| 矜持 | きょうじ |  | 自分の能力への自信・誇り・プライド |
| 僭越 | せんえつ |  | 自分の立場を越えた言動をすること（「僭越ながら」） |

## 💡 学習のコツ

- 単語の **文脈** の中で意味を理解して覚える
- **例文** を作って実際に使ってみよう
- 同義語・反意語も合わせて確認すると理解が深まる
