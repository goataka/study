# 小学4年 官庁世紀喜旗器泣救共鏡極

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 官庁 | かんちょう |  | 国の政府の役所 |
| 世紀 | せいき |  | 100年間のこと |
| 喜 | よろこ | き | 嬉しく思うこと |
| 旗 | はた | き | 棒に布を付けた目印 |
| 器 | うつわ | き | 物を入れる容器 |
| 泣 | な | きゅう | 涙を流すこと |
| 救 | すく | きゅう | 危険から助けること |
| 共 | とも | きょう | 一緒に・ともに |
| 鏡 | かがみ | きょう | 姿を映すもの |
| 極 | きわ | きょく | 限界まで追求すること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
