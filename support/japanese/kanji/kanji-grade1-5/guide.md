# 小学1年 犬見五三子四糸字耳七

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 犬 | いぬ | けん | 人と仲良く暮らす動物のこと |
| 見 | み | けん | 目で確かめること |
| 五 | いつ | ご | 数の5のこと |
| 三 | みっ | さん | 数の3のこと |
| 子 | こ | す | 子どものこと |
| 四 | よっ | し | 数の4のこと |
| 糸 | いと | し | 布や縫い物に使う細いもの |
| 字 | じ |  | 文字のこと |
| 耳 | みみ | じ | 音を聞く体の部分 |
| 七 | なな | しち | 数の7のこと |

## 💡 学習のコツ

- 訓読みは **日本語のことば** としてイメージして覚える
- 読み方だけでなく **書き方** も合わせて練習しよう
- クイズで繰り返し練習するとおぼえやすい
