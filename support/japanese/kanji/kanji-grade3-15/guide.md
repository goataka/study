# 小学3年 配二倍箱畑を耕出発坂道板反対皮美

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 配 | くば | はい | 分けて渡すこと |
| 倍 | ばい |  | 数が何倍かを表す言葉 |
| 箱 | はこ |  | 物を入れる容器 |
| 畑 | はたけ |  | 野菜などを育てる土地 |
| 発 | はつ |  | 出ること・始まること |
| 坂 | さか |  | 傾いた道 |
| 板 | いた |  | 薄く平たい木 |
| 反 | はん |  | 逆のこと |
| 皮 | かわ | ひ | 物の外側の薄い膜 |
| 美 | うつく | び | きれいなこと |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
