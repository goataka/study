# 小学3年 去橋曲銀行苦君係軽血決

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 去 | さ | きょ | 離れていくこと |
| 橋 | はし | きょう | 川などをこえるための構造物 |
| 曲 | ま | きょく | まっすぐでなく折れること |
| 銀行 | ぎんこう |  | お金を預かったり貸したりする場所 |
| 苦 | くる | く | つらいこと |
| 君 | きみ | くん | 相手をよぶ言葉 |
| 係 | かかり | けい | 担当の仕事・役割のこと |
| 軽 | かる | けい | 重さが少ないこと |
| 血 | ち | けつ | 体の中を流れる赤い液体 |
| 決 | き | けつ | 物事をはっきりさせること |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
