# 小学3年 文章乗神様整昔話他の人反対第一問題炭火

## 📊 一覧

| 漢字 | 訓読み | 音読み | 意味 |
|------|--------|--------|------|
| 章 | しょう |  | 文のまとまり |
| 乗 | の |  | 乗り物に乗ること |
| 神 | かみ | しん | 神聖な存在 |
| 整 | ととの |  | きちんとすること |
| 昔 | むかし |  | 過去のこと |
| 他 | ほか | た | それ以外のこと |
| 対 | たい |  | 向き合うこと・相手のこと |
| 第 | だい |  | 順番を表す言葉 |
| 題 | だい |  | テーマ・問題のこと |
| 炭 | すみ | たん | 木を焼いて作った燃料 |

## 💡 学習のコツ

- 訓読みと音読みの両方を確認しよう
- 熟語（2文字以上の組み合わせ）で音読みを覚えると効果的
- クイズで繰り返し練習するとおぼえやすい
