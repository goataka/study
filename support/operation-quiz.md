# 機能リファレンス — 問題画面

クイズ開始後に表示される画面です。左側で問題に回答し、右側のメモ帳で計算や下書きができます。

![問題画面](../images/06-quiz-screen.png)

## 問題エリア（左側）

| パーツ | 説明 |
|--------|------|
| プログレスバー | 全問題中の現在の進捗を表示する |
| 問題番号 | 「1/10」のように現在の問題番号を表示する |
| 単元名バッジ | 現在の問題の単元名を表示する |
| ✕（やめるボタン） | クイズをやめてスタート画面に戻る（確認メッセージあり） |
| 問題文 | 出題される問題を表示する |
| 選択肢ボタン | 4択の回答候補。タップ（クリック）して回答する |
| 前へ／次へボタン | 問題を前後に移動する |
| 採点するボタン | 全問回答後に表示。クリックすると結果画面へ進む |

### 外部仕様

- 選択肢を選ぶまで「次へ」ボタンは無効状態で、回答すると有効になる。
- すべての問題に回答すると「次へ」の位置に「採点する」ボタンが表示される。
- 「前へ」で戻った問題は、選択済みの回答が保持された状態で再表示される。
- 練習モード（ストレート順）で開始した場合、クイズ画面に `practice-mode` クラスが付与される。本番クイズでは付与されない。

## 回答フィードバック

選択肢を選んだ後に表示されます。

![回答フィードバック](../images/06b-quiz-feedback.png)

| パーツ | 説明 |
|--------|------|
| ⭕ 正解 / ✕ 不正解 | 正誤を表示する |
| 解説テキスト | 正解の理由や補足説明を表示する |

### 外部仕様

- 不正解の場合は正しい選択肢を併せて表示する。
- フィードバック表示後も「前へ／次へ」で問題を移動できる。

## メモエリア（右側）

問題を解くときに使えるメモ帳です。

| パーツ | 説明 |
|--------|------|
| 🗑️（全部消すボタン） | メモキャンバスをすべて消去する |
| 消しゴムボタン | 消しゴムモードに切り替える（もう一度押すとペンに戻る） |
| 線の太さ（ふつう/太い/極太） | ペンの太さを選択する |
| 色（黒/青/赤/緑） | ペンの色を選択する |
| メモキャンバス | 自由に書き込めるキャンバス |

### 外部仕様

- メモの内容は問題を移動しても保持され、クイズを終了するまで利用できる。
- 消しゴムモード中はもう一度消しゴムボタンを押すとペンモードに戻る。

## 手書き文字入力（text-input 問題）

記述式問題では、メモエリアが手書き文字入力に切り替わります。

| パーツ | 説明 |
|--------|------|
| 手書きキャンバス | 1文字ずつ書いて文字を入力する |
| 候補ボタン | 書いた文字の認識候補を表示する。クリックすると解答欄に入力される |
| 🗑️（全部消すボタン） | キャンバスをすべて消去する |

### 外部仕様

- ひらがなで答える問題では、認識候補にひらがな以外の文字は表示されない。
- 候補ボタンをクリックすると、その文字が解答欄に追加される。
