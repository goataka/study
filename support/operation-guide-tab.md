# 機能リファレンス — ガイドタブ

教科タブで「🚀 ガイド」を選択すると表示されます。左列のメニューからサポート情報を切り替えます。

![ガイドタブ](../images/09-guide-tab.png)

## 左列メニュー

| メニュー                  | 説明                                                                         |
| ------------------------- | ---------------------------------------------------------------------------- |
| 🏠 はじめに               | アプリの概要とサポート情報を表示する                                         |
| 📖 使い方                 | 使い方を3つのページに分けて表示する（下のサブタブ参照）                      |
| 🖥️ 機能リファレンス       | 各画面と機能の仕様を画面・パーツごとのサブタブで表示する（下のサブタブ参照） |
| 📚 教科・単元             | 全教科の単元一覧（解説・確認リンク付き）を表示する                           |
| ❓ トラブルシューティング | よくある質問と困ったときの対処法を表示する                                   |

## 使い方のサブタブ

「📖 使い方」を選ぶと、上部に3つのサブタブが表示されます。

| サブタブ            | 説明                                                         |
| ------------------- | ------------------------------------------------------------ |
| 🚀 スタートアップ   | 名前・プロフィール・文字サイズなど、最初の設定だけを表示する |
| 📅 毎日の使い方     | おすすめタブを使った毎日の学習の進め方を表示する             |
| 🔖 教科指定の使い方 | 教科タブから単元を自分で選ぶ使い方を表示する                 |

## 機能リファレンスのサブタブ

「🖥️ 機能リファレンス」を選ぶと、上部に画面・パーツごとのサブタブが表示されます。

| サブタブ        | 説明                                               |
| --------------- | -------------------------------------------------- |
| 🧭 ヘッダー     | 常時表示されるヘッダーとプロフィール設定画面の仕様 |
| 🚀 スタート画面 | 教科タブ・おすすめタブ・単元一覧・単元詳細の仕様   |
| ✏️ 問題画面     | クイズ中の問題エリア・フィードバック・メモの仕様   |
| 🏁 結果画面     | 採点後の結果表示と画面遷移の仕様                   |
| 📈 進度タブ     | 教科ごとの進度表示の仕様                           |
| 📖 ガイドタブ   | このページ（ガイドメニュー）の仕様                 |
| ⚙️ 管理タブ     | 学習データの管理機能の仕様                         |
| 🔧 全体・その他 | URL での直接アクセスや画面サイズ対応などの全体仕様 |

## 外部仕様

- 選択中のメニューはハイライト表示される。
- 「📖 使い方」と「🖥️ 機能リファレンス」は、選択するとそれぞれのサブタブが上部に表示される。
- メニューは URL フラグメント（`#subject=support&supportMenu=...`）と連動し、共有したリンクから特定のメニューを直接開ける。
