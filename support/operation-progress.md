# 機能リファレンス — 進度タブ

教科タブで「📈 進度」を選択すると表示されます。左列の教科をクリックして教科ごとの進度を確認できます。

![進度タブ](../images/07-progress-tab.png)

## 左列（教科リスト）

| パーツ             | 説明                                                     |
| ------------------ | -------------------------------------------------------- |
| 教科ボタン         | 各教科をクリックすると右列に進度の詳しい情報が表示される |
| 対象学年フィルター | 小学 / 中学 / 高校 で教科内の学年を絞り込む              |

## 右列（進度の詳しい情報）

| パーツ             | 説明                                               |
| ------------------ | -------------------------------------------------- |
| 学習完了ルール ℹ️  | 学習完了の条件を吹き出しで確認できる               |
| 学年別タブ         | 学年ごとにグループ化した単元の進度を表示する       |
| 分野別タブ         | 分野ごとにグループ化した単元の進度を表示する       |
| マトリクスタブ     | 単元の進度を表形式で表示する                       |
| 学習状況フィルター | すべて／未学習／学習中／学習済み で単元を絞り込む  |
| 単元名クリック     | 単元名をクリックすると教科タブの該当単元に遷移する |

### 学習完了ルール

- 各教科は、収録されている**全問題を検定済（ステージ3）**にすると「学習完了」になります。
- UI では ✅ **学習完了（全問検定済）** と表示されます。
- 進度タブの ℹ️ から、教科一覧の見方とあわせてこの条件を確認できます。

## 外部仕様

- 教科ボタンには、その教科の学習済み数／全体数（例：0/134）が表示される。
- 学年別・分野別・マトリクスのいずれのタブでも、学習状況フィルターは共通で機能する。
- マトリクスタブでは、行が学年、列が分野の表形式で各単元が配置される。
- 単元名をクリックすると、対応する教科タブに切り替わり、その単元が選択された状態になる。
- 学習完了の判定は「単元数」ではなく、各教科に含まれる全問題が検定済かどうかで行う。
