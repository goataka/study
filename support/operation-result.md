# 機能リファレンス — 結果画面

全問回答・採点後に表示される画面です。スコアと各問題の正誤を確認し、次の操作を選べます。

![結果画面](../images/10-result-screen.png)

| パーツ                   | 説明                                                             |
| ------------------------ | ---------------------------------------------------------------- |
| クイズ結果               | 正解数（例：8/10問正解）を表示する                               |
| 正解メッセージ           | 正解率に応じたメッセージを表示する                               |
| 問題一覧                 | 各問題の正誤・正解・解説を一覧で表示する                         |
| 学習を終わるボタン       | おすすめタブに戻り、次のおすすめ単元を表示する（最も目立つ配色） |
| もう一度ボタン           | 同じ単元を再度練習する                                           |
| スタート画面に戻るボタン | スタート画面に戻る                                               |

## 外部仕様

- 結果画面では正解率（％）と「n/m 正解」の両方が表示される。
- 「もう一度」をクリックすると、同じ単元のクイズが最初の問題から再開される。
- 「スタート画面に戻る」をクリックすると、選択していた教科のスタート画面に戻る。
- 問題一覧では各問題に対して「あなたの回答」と「正解」、解説が並べて表示される。
