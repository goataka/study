# 機能リファレンス — スタート画面

アプリを開いたときに最初に表示される画面です。教科タブの切り替えと、単元の選択・詳細表示を行います。

## 教科タブ

画面上部のタブで、表示する内容を切り替えます。

![教科タブ（ガイド）](../images/02-start-guide-tab.png)

| タブ        | 説明                                                                  |
| ----------- | --------------------------------------------------------------------- |
| 🎯 おすすめ | 全教科のおすすめ単元と学習状況サマリを表示する（2回目以降の初期表示） |
| 🚀 ガイド   | 使い方・教科・単元・サポート情報を表示する（初回表示）                |
| 📈 進度     | 教科別の学習進度を分野別・学年別に確認できる                          |
| 🌐 英語     | 英語の単元一覧を表示する                                              |
| 📐 数学     | 数学の単元一覧を表示する                                              |
| 📖 国語     | 国語の単元一覧を表示する                                              |
| 🕒 履歴     | 学習履歴を「単元毎」「問題毎」で確認できる                            |
| ⚙️ 管理     | 学習データの読み込み・保存・初期化ができる                            |

### 外部仕様

- 選択中のタブはハイライト表示される。
- 初回起動時は「🚀 ガイド」、2回目以降は「🎯 おすすめ」が初期表示となる。
- 各タブは URL フラグメント（`#subject=...`）と連動し、選択すると URL が更新される。

## おすすめタブ

おすすめタブ選択時は、全教科横断のおすすめ単元が表示されます。

![おすすめタブ](../images/03-start-osusume-tab.png)

### 学習状況パネル

| パーツ                          | 説明                                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------------- |
| 学習数 n/目標                   | 今日の学習数と目標数を星の上に表示する                                                 |
| 星（☆/⭐）                      | 目標数に連動した星。学習済みは ⭐、未達成は ☆                                          |
| 次の単元                        | 最初に取り組むおすすめ単元（教科名 › トップ › 親 › 単元名）を星の下に表示する          |
| スタートボタン                  | おすすめ先頭単元を開く（未学習は `📖 解説`、学習済みは `✅ 確認`）                     |
| 取り組み中の単元 / 終わった単元 | スタートボタンの下に当日学習した単元を進行状態ごとに表示する（各リストのみスクロール） |

### 今日の単元リスト

| パーツ             | 説明                                                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| タイトル右の ℹ️    | クリックすると選び方の説明を表示する（未学習優先 / 学習済📝7日後・復習済📜14日後の復習対象 / 検定済🎓除外 / 国語→数学→英語優先） |
| 目標数コントロール | おすすめ表示の目標数（2/3/5/8/13）を切り替える。デフォルトは3とする                                                              |
| 単元カード         | 教科絵文字・単元名・ステージ表示・進捗バーを表示。クリックで単元を選択する                                                       |
| 目標ライン         | 「🎯 目標ここまで」で目標分との境界を表示する                                                                                    |
| 🚀 もっと追加      | クリックするとおすすめ単元を追加で表示する                                                                                       |

### 外部仕様

- 目標数を変更すると、表示されるおすすめ単元の件数と目標ラインの位置が連動して変わる。
- 「学習状況」タブと「シェア」タブを切り替えると、右パネルの表示内容が入れ替わる。
- シェア用のサマリには学習日の日付（📅）が含まれる。

### おすすめ単元の選定方法

おすすめ一覧は、目標数に追加分を加えた件数を上限として、次の順で作成されます。

1. 検定済み（ステージ 3）、全問習得済み、前提未達、学年上限超過の単元を除外する。
2. 未学習（ステージ 0）と、待機期間を過ぎた復習対象を候補にする。学習済み（ステージ 1）は 7 日、復習済み（ステージ 2）は 14 日経過後に復習対象になる。
3. 未学習と復習を交互に配置する。各候補群は国語 → 数学 → 英語の教科順で巡回し、復習候補の同一教科内の順序はランダムにする。
4. 候補が不足した場合は、条件を満たす学習済み単元を補完する。

単元カードの進捗は `習得済み問題数 / 全問題数 × 100`（整数四捨五入）です。目標数は 2 / 3 / 5 / 8 / 13 から選び、初期値は 3 です。

## 単元一覧（教科タブ）

教科タブを選択すると、左パネルに単元一覧が表示されます。

![単元一覧（英語）](../images/04-start-english-unit-list.png)

| パーツ                 | 説明                                                                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 学習状況フィルター     | すべて／未学習／学習中／学習済み で単元を絞り込む                                                                       |
| 分野別／学年別ボタン   | 単元を分野順または学年順に並べ替える                                                                                    |
| 学習済みを隠すボタン   | 学習済みの単元を非表示にする                                                                                            |
| 分野／学年の解説ボタン | 各グループ見出しの `📖 解説` から、その分野や学年に対応した解説を表示する                                               |
| 単元アイテム           | クリックすると単元を選択し、右パネルに詳細が表示される。単元名の横に `📝` 学習済 / `📜` 復習済 / `🎓` 検定済 を表示する |
| 進捗バー               | 各単元の正解率を棒グラフで表示する                                                                                      |
| 学年バッジ             | 対象学年を色付きバッジで表示する（赤＝小学、青＝中学、緑＝高校）                                                        |

### 外部仕様

- 学習状況フィルターで該当単元が0件の学年フィルターは無効状態（クリック不可）になる。
- 分野別／学年別の切り替えはグループ見出しの並びを変えるが、単元自体は同じものが表示される。
- 親カテゴリのグループ見出しは折りたたみ・展開ができる。
- 学年フィルター（小学／中学／高校）と学習状況フィルターは併用できる。

## 履歴タブ

履歴タブでは、左列の教科メニューで教科を選び、右列でその教科の学習履歴を「単元毎」「問題毎」で切り替えて確認できます。

| パーツ              | 説明                                                       |
| ------------------- | ---------------------------------------------------------- |
| 教科メニュー        | 英語 / 数学 / 国語 から表示したい履歴の教科を選ぶ          |
| 単元毎 / 問題毎切替 | 選択中の教科について、単元集計と問題集計を切り替える       |
| 単元毎一覧          | 単元ごとの学習回数と正答率を表示する                       |
| 問題毎一覧          | 問題ごとの正解数・不正解数と直近に取り組んだ単元を表示する |

### 外部仕様

- 履歴タブは「📖 国語」と「⚙️ 管理」の間に表示される。
- 左列の教科メニューは、進度タブと同じリスト形式で表示される。
- 「単元毎」表示では単元ごとの学習回数と正答率を表示する。
- 「問題毎」表示では問題ごとの正解数・不正解数と直近単元を表示する。

## 単元詳細（右パネル）

単元を選択すると右パネルに詳細が表示されます。上部のタブで内容を切り替えます。

### タブ

| タブ    | 説明                               |
| ------- | ---------------------------------- |
| 📖 解説 | 選択した単元の解説ページを表示する |
| ✅ 確認 | クイズの設定と開始ボタン           |
| 📋 問題 | 単元の問題一覧を表示する           |
| 📊 履歴 | 過去の回答履歴を表示する           |

直前に開いていたタブは、別の単元を選んだときも引き継がれる。

### 解説タブ

選択した単元の解説ページをアプリ内に表示します。文字サイズは「小/中/大」ボタンと連動します。

![単元詳細 - 解説タブ](../images/05-unit-detail-guide-tab.png)

### 確認タブ（クイズ設定）

![単元詳細 - 確認タブ](../images/05b-unit-detail-kakunin-tab.png)

| パーツ                               | 説明                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| スタートボタン                       | 設定した条件でクイズを開始する                               |
| 前提単元 / 着手状況 / 完了ステータス | パネル上部に、前提単元名・着手可否・完了状態を表示する       |
| 問題数                               | 5問 / 10問 / 20問 / 全て から選択する。デフォルトは5問とする |
| 並び順                               | 順番通り（ストレート）またはランダムで出題する               |
| 学習済                               | 学習済みの問題を含めるかどうか                               |
| ✅ 履修済にするボタン                | 選択した単元を履修済みとしてマークする                       |

#### 外部仕様

- 問題数・並び順・学習済の設定は記憶され、次回のクイズ設定にも引き継がれる。
- 並び順で「ストレート」を選んでクイズを開始すると、練習モード（`practice-mode`）として開始される。
- 「履修済にする」を実行すると確認ダイアログが表示され、確定すると単元が学習済み扱いになる。

### 問題タブ

![単元詳細 - 問題タブ](../images/05c-unit-detail-mondai-tab.png)

| パーツ                              | 説明                                   |
| ----------------------------------- | -------------------------------------- |
| すべて／未学習／学習済み フィルター | 表示する問題を絞り込む                 |
| 問題一覧                            | 問題文と正解・不正解状況を一覧表示する |

### 履歴タブ

![単元詳細 - 履歴タブ](../images/05d-unit-detail-history-tab.png)

過去のクイズ結果を日付ごとにまとめて表示します。

#### 外部仕様

- 各履歴はクリックで詳細（各問題の正誤）を展開できる。
- 「履修済にする」で手動記録した記録はスコアが「-」と表示され、展開用の矢印を持たず詳細は開かない。
