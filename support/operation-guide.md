# 機能リファレンス

学習アプリの各画面と機能の仕様を、外から見える動作（操作と結果）の観点でまとめた資料です。
使い方の手順ではなく、「どこに何があり、押すと何が起きるか」を確認するためのものです。

アプリ内では「🚀 ガイド」タブ →「🖥️ 機能リファレンス」から、画面・パーツごとのサブタブで参照できます。各ページは以下に分かれています。

## 仕様の範囲

このリファレンスを、画面の再作成に必要な外部仕様の正とします。各ページには、次の内容を記載します。

- 操作対象、初期状態、操作後の表示と画面遷移
- 表示される数値・ステータスの定義と計算方法
- URL フラグメント、保存データ、エラー時などの境界条件
- E2E のユースケースで確認している操作

内部のクラス構成や IndexedDB のキーなど、画面から直接見えない仕組みは [管理タブのシステム仕様](../operation-admin/#システム仕様) と [技術リファレンス](../technical-reference/) にまとめます。

- [🧭 ヘッダー](../operation-header/) — 常時表示されるヘッダーとプロフィール設定画面
- [🚀 スタート画面](../operation-start/) — 教科タブ・おすすめタブ・単元一覧・単元詳細
- [✏️ 問題画面](../operation-quiz/) — クイズ中の問題エリア・フィードバック・メモ
- [🏁 結果画面](../operation-result/) — 採点後の結果表示と画面遷移
- [📈 進度タブ](../operation-progress/) — 教科ごとの進度表示
- [🕒 履歴タブ](../operation-start/#履歴タブ) — 単元毎 / 問題毎で学習履歴を確認
- [📖 ガイドタブ](../operation-guide-tab/) — ガイドメニューの仕様
- [⚙️ 管理タブ](../operation-admin/) — 学習データの管理機能
- [🔧 全体・その他](../operation-misc/) — URL での直接アクセスや画面サイズ対応などの全体仕様

## 使い方との関係

[スタートアップ](../startup-guide/)、[毎日の使い方](../daily-guide/)、[教科指定の使い方](../subject-guide/) は、ここで定義した外部仕様を操作手順として説明します。基本学習フローは E2E の `app/e2e/features/usecases/start-basic-flow.feature` と一致します。
