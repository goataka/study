# 機能リファレンス

学習アプリの各画面と機能の仕様を、外から見える動作（操作と結果）の観点でまとめた資料です。
使い方の手順ではなく、「どこに何があり、押すと何が起きるか」を確認するためのものです。

アプリ内では「🚀 ガイド」タブ →「🖥️ 機能リファレンス」から、画面・パーツごとのサブタブで参照できます。各ページは以下に分かれています。

- [🧭 ヘッダー](../operation-header/) — 常時表示されるヘッダーとプロフィール設定画面
- [🚀 スタート画面](../operation-start/) — 教科タブ・おすすめタブ・単元一覧・単元詳細
- [✏️ 問題画面](../operation-quiz/) — クイズ中の問題エリア・フィードバック・メモ
- [🏁 結果画面](../operation-result/) — 採点後の結果表示と画面遷移
- [📈 進度タブ](../operation-progress/) — 教科ごとの進度表示
- [📖 ガイドタブ](../operation-guide-tab/) — ガイドメニューの仕様
- [⚙️ 管理タブ](../operation-admin/) — 学習データの管理機能
- [🔧 全体・その他](../operation-misc/) — URL での直接アクセスや画面サイズ対応などの全体仕様
