# 機能リファレンス — ヘッダー

画面上部に常時表示されるバーです。どの画面に移動しても表示され、アプリ全体に関わる操作をまとめています。

![ヘッダー](../images/01-header.png)

## ヘッダーのパーツ

| パーツ                 | 説明                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| アプリ名（タイトル）   | クリックするとハッシュなしのトップ URL に戻る（クイズ中は確認ダイアログを表示してから移動する） |
| ユーザー名ボタン       | クリックするとプロフィールダイアログを開く                                                      |
| アバター画像           | クリックするとプロフィールダイアログを開く                                                      |
| 今日の日付             | 現在の日付を「YYYY/MM/DD（曜日）」形式で表示する                                                |
| 🔄（更新ボタン）       | ページを再読み込みする（日付の右に表示）                                                        |
| 小/中/大（文字サイズ） | アプリ全体の文字サイズを切り替える（解説タブにも反映）。初回起動時のデフォルトは「中」とする    |

## 外部仕様

- ヘッダーはスクロールしても常に画面上部に固定される。
- 文字サイズの選択は記憶され、次回起動時も同じサイズで表示される。
- 文字サイズを「大」にすると `body` に `font-size-large` クラスが付与され、「小」に戻すと除去される。
- クイズの回答中にアプリ名をクリックした場合は、回答内容が失われる旨の確認を経てから遷移する。
- ヘッダーにはユーザー追加用の「＋」ボタンは表示しない（ユーザーの追加はプロフィールダイアログから行う）。

## プロフィール設定画面

ヘッダーのユーザー名またはアバター画像をクリックすると表示されるポップアップです。表示名の変更やユーザーの切り替え・追加をまとめて行えます。

| パーツ                     | 説明                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 表示名                     | 現在のユーザー名を表示。クリックすると編集モードになり、名前を変更できる                                                       |
| プロフィール画像を変更する | クリックするとアバター画像のトリミング画面を開く                                                                               |
| ユーザー切り替え一覧       | 登録済みユーザーの一覧を表示。「切り替え」ボタンで別ユーザーに切り替わる（ページ再読み込み）                                   |
| ＋ 新しいユーザーを追加    | クリックするとユーザー名入力欄が表示される。名前を入力して「追加」ボタンで新しいユーザーを追加し切り替わる（ページ再読み込み） |
| ✕（閉じるボタン）          | 設定画面を閉じる                                                                                                               |
| 背景クリック / Escape      | 設定画面を閉じる                                                                                                               |

### 外部仕様

- 表示名を保存すると、ヘッダーのユーザー名へ即座に反映される。
- ユーザーの切り替え・追加を行うと、選んだユーザーの学習データを読み込むためにページが再読み込みされる。
- 表示名の編集を確定せずに閉じた場合、変更は反映されない。
