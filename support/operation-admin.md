# 機能リファレンス — 管理タブ

教科タブで「⚙️ 管理」を選択すると表示されます。学習データのインポート・エクスポート・初期化などを行えます。

![管理タブ](../images/08-management-tab.png)

## 左メニュー

| メニュー      | 説明                                                             |
| ------------- | ---------------------------------------------------------------- |
| 👥 ユーザー   | ユーザーの切り替え・追加・削除と、ユーザー単位のデータ管理を行う |
| ✅ データ更改 | データのインポート・エクスポート・初期化を行う                   |
| 📖 データ参照 | 設定・履歴・学習済み問題・連続正解データを確認・コピーする       |
| 🧩 データ仕様 | アプリのデータ仕様の説明を表示する                               |

## ユーザーメニュー（👥 ユーザー）

| パーツ                                | 説明                                                                 |
| ------------------------------------- | -------------------------------------------------------------------- |
| ユーザー一覧                          | 登録済みユーザーを表示する。使用中のユーザーには「（使用中）」が付く |
| 切り替え                              | 別のユーザーに切り替える（ページ再読み込み）                         |
| 🗑️（削除）                            | ユーザーを削除する（ゲストは削除できない）                           |
| ＋ 追加                               | 名前を入力して新しいユーザーを追加し切り替える（ページ再読み込み）   |
| ⬇️ 全ユーザーを一括エクスポート       | すべてのユーザーのデータをまとめて保存する                           |
| ⬇️ 現在のユーザーを個別エクスポート   | 使用中のユーザーのデータだけを保存する                               |
| 🗑️ 現在のユーザーのデータを初期化する | 使用中のユーザーの学習データを削除する                               |

## データ更改メニュー（✅ データ更改）

| タブ            | 説明                                                                            |
| --------------- | ------------------------------------------------------------------------------- |
| 📥 インポート   | 保存した JSON ファイルを選択してデータを更新する                                |
| 📤 エクスポート | すべての学習データを JSON ファイルとして保存する（バックアップ用）              |
| 🗑️ 初期化       | 全データ削除でのリセット、またはサンプルデータでの初期化を行う（2段階確認あり） |

### 外部仕様

- 管理タブを開くと、デフォルトで「✅ データ更改」の「インポート」コンテンツが表示される。
- メニューボタンを再クリックしても、表示中のコンテンツは閉じない。
- 「📤 エクスポート」を実行すると、学習データの JSON ファイルのダウンロードが始まる。
- 「🗑️ 初期化」は誤操作を防ぐため、2段階の確認を経てから実行される。

## データ参照メニュー（📖 データ参照）

| パーツ         | 説明                                               |
| -------------- | -------------------------------------------------- |
| データ種別タブ | 設定 / 履歴 / 学習済み問題 / 連続正解 を切り替える |
| 内容表示       | 選んだデータの内容を表示する                       |
| コピーボタン   | 表示中のデータをクリップボードにコピーする         |

## システム仕様

### 保存単位とデータの反映

- 学習データはブラウザの IndexedDB（データベース `studyProgressDB`、オブジェクトストア `keyValue`）にユーザー単位で保存されます。
- クイズの採点ごとに、問題別統計、間違えた問題、連続正解数、習得済み問題、履歴を保存します。
- 「学習済み」は問題単位で管理します。未学習の問題は 3 回連続正解、ステージ 1 または 2 の復習問題は 1 回正解で習得済みになります。不正解になると未習得問題の連続正解数は 0 に戻り、間違えた問題に追加されます。
- 単元ステージは 0=未学習、1=学習済、2=復習済、3=検定済です。単元詳細で「履修済にする」を実行すると、回答なしで対象単元の全問題を習得済みにし、スコアなしの手動履歴を追加します。
- ステージを 0→1、1→2 に進めると対象単元の問題別進捗をリセットします。2→3 ではリセットしません。3 の単元はおすすめから除外されます。

### インポート・エクスポート

- エクスポートは現在のユーザーの全保存データを JSON としてダウンロードします。ユーザー管理の一括エクスポートは全ユーザー分をまとめます。
- インポートは JSON ファイルを選択してプレビューし、形式を検証してから保存します。設定データは参照用で、インポートによる変更対象にはしません。
- 初期化は「全データ削除」と「サンプルデータで初期化」を分け、確認ダイアログを経てから実行します。完了後は保存データとメモリ上のキャッシュを再読み込みします。
