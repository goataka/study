# 毎日の使い方

毎日の学習は「🎯 おすすめ」タブから始めるのがおすすめです。
今日学習するとよい単元が自動で選ばれます。

## ステップ1：おすすめタブを開く

2回目以降は、起動すると「🎯 おすすめ」タブが自動で表示されます。
初回は「🚀 ガイド」タブが表示されるので、タブをクリックして「🎯 おすすめ」を選んでください。

## ステップ2：今日の学習状況を見る

「🎯 おすすめ」タブには、今日の学習の進み具合が表示されます。

- 画面上部に **学習状況の星（☆／⭐）** が表示されます
  - 目標数と今日の学習数（例: 学習数 2/5）が星の上に表示されます
  - 学習するごとに星が埋まっていきます
- 星の下に **次の単元** が表示されます
  - 教科名と単元名が太字で表示されます

## ステップ3：学習を始める

- 「開始する」ボタンをクリックすると、おすすめ単元を開きます
  - 未学習の単元: `📖 解説`
  - 学習済みの単元: `✅ 確認`
- 「開始する」の下に、`取り組み中の単元` と `終わった単元` が一覧表示されます
- 単元カードをクリックして、特定の単元を選ぶこともできます
- 単元にはステージが表示されます
  - `📝` 学習済
  - `📜` 復習済
  - `🎓` 検定済

## ステップ4：問題に挑戦する

選択肢をタップ（クリック）して回答しましょう。

- 答えを選ぶとすぐに正解・不正解がわかります
- 解説も表示されるので、間違えても大丈夫です
- 全問終わると結果が表示されます
- 「学習を終わる」を押すと次のおすすめ単元に進めます

## 基本的な操作

| 操作 | 説明 |
|------|------|
| 選択肢をタップ | 4択から正しいと思う答えを選ぶ |
| 解説を見る | 回答後に解説が表示される |
| 次の問題へ | 「次へ」ボタンで次の問題に進む |
| 結果を確認 | 全問終了後にスコアが表示される |
| もう一度 | 結果画面から同じ単元を再挑戦できる |
| 学習を終わる | 次のおすすめ単元に進む |
